# Contributing to MERKATO

Thank you for contributing to Ethiopia's premier digital marketplace!

## Branching Conventions
- `feature/<name>`: New UI or backend features
- `fix/<name>`: Bug fixes
- `docs/<name>`: Documentation updates
- `refactor/<name>`: Code cleanup and performance optimizations

## Commit Message Format (Conventional Commits)
- `feat(scope): add new feature`
- `fix(scope): resolve bug`
- `docs(scope): update documentation`
- `style(scope): CSS design improvements`
- `refactor(scope): refactor internal logic`
- `chore(scope): repository maintenance`
