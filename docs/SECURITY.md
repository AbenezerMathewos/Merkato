# Security Policy

## Reporting Vulnerabilities
If you discover a security issue or vulnerability in MERKATO, please email security@merkato.com directly. Do NOT open public GitHub issues for security reports.

## Protections Implemented
- Input sanitization against XSS
- CSRF protection & strict SameSite cookie policies
- Sliding window API rate limiting
- Content Security Policy (CSP) headers

### Incident Response SLA
Critical vulnerabilities are acknowledged within 24 hours and patched within 72 hours.
